# Exemple de evitat — SageBeauty

Postari/stiluri pe care Andreea NU le vrea — fie pentru ca a incercat si nu a functionat, fie pentru ca nu se potrivesc vocii SageBeauty (ex: postari generice de "influencer beauty", ton prea corporatist, cliseee).

Cand vezi ceva ce nu vrei sa semene continutul tau, adauga aici in formatul:

```
## [titlu scurt / sursa]
**De ce nu se potriveste:** [1-2 propozitii concrete]

[textul sau descrierea]
```

## Carusel cu iconite line-art pe fundal plat roz (fond de ten, v1, 2026-09-23)
**De ce nu se potriveste:** Andreea: "nu mi se pare asa wow". Curat si coerent, dar plat — iconita
subtire + text pe fundal gol nu opreste scroll-ul si nu arata nimic real (nici piele, nici produs,
nici rezultat). Inlocuit cu versiunea cu imagini reale, acum etalon in `good_posts.md`.

## Caption cu experienta inventata (exfoliere, v1, 2026-09-22)
**De ce nu se potriveste:** "Am exfoliat aproape zilnic o vara intreaga si pielea mea arata mai
iritata" — agentul a inventat o experienta a Andreei. Incalca regula de baza: nimic inventat.
Refacut cu un detaliu real (tonerul Glow Recipe din `produse_incercate.md`).
